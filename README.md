# Lory Bolsas Personalizadas

Site institucional e catálogo da Lory Bolsas Personalizadas, desenvolvido com Next.js.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Verificar produção

```bash
npm run check
```

Esse comando executa a checagem de tipos e o build de produção.
